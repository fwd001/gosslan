## Lanct 项目（无服务器 P2P 局域网即时通讯）

完成 `D:\code\lanct` 整体搭建（Tauri v2 + Vue 3 Composition API + TypeScript + Vite）。

### 后端（Rust）
- 设备指纹（machine-uid）、SQLite 存储（rusqlite bundled）
- UDP 广播 + 组播发现、TCP 分帧传输、建链规则：**device_id 字典序小者主动拨号**
- E2EE：`crypto.rs`（X25519 ECDH + Ed25519 签名 + ChaCha20-Poly1305）
- Gossip 广播：`gossip_engine.rs`（Bloom Filter + LRU 去重、fan-out、TTL 衰减）

- 离线补发（outbox 表）、共享目录（防目录穿越）、群密钥分发（GroupKey）
- 身份密钥与设备指纹存 `settings` 表；好友公钥从 announce 广播学习后持久化到 `friends` 表

### 前端（Vue 3）
- **弃用 Ant Design Vue**，改用 Tailwind CSS + Headless UI + Lucide 图标（用户明确要求）
- `ResponsiveLayout.vue`：PC 三栏 + 移动端单栏滑动切换 + 底部导航 + 安全区
- `VirtualList.vue` 虚拟滚动 + `message.worker.ts` Web Worker 消息合并排序
- 深色模式（`.dark` class）+ CSS 变量主题色/字体注入
- Pinia stores：`useAppStore.ts` / `useChatStore.ts`

### 关键决策
- UI 库从 AntD 换成 Tailwind + Headless UI + Lucide
- 单聊 ECDH 加密、群聊群密钥对称加密；中继节点只能透传密文
- 前端收到的消息是明文（Rust 已解密），Worker 只做列表合并/排序
